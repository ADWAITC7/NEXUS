# NEXUS

A small landing-page experiment built because I genuinely love making weird, interactive web experiences.

NEXUS started as a **Framer-inspired landing page experiment**, mixing React, Three.js, React Three Fiber, procedural visuals, and motion to see how far I could push a simple webpage.

Nothing too serious — just me messing around, learning, and creating new shizz. ⚡

## Built With

* React
* TypeScript
* Vite
* Three.js
* React Three Fiber

## Run Locally

```bash
npm install
npm run dev
```
